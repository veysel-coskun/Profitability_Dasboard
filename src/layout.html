      Central forecasts

      P&L bridge to Variable Margin

      Central forecast profitability matrix: gross sales, allowances, cost of goods, royalties, then warehousing and freight. VM = GMR − warehousing − freight. Logistics apply to Domestic only. Submission-based forecasts use the submitted P&L lines instead.

      Phased forecasts

      Phased forecasts split each forecast by month and fit it to the monthly sales plan; uplift = phased ÷ before phasing. See the Monthly tab.

      Comparing different methods

      ▤

      Submission-based forecasts

      Some scenarios are consolidated from market submissions rather than built from the central matrix, so their P&L lines are mapped onto the same layout down to variable margin. Central costs and closeouts are excluded.

      !

      Not always like-for-like

      Scenarios built with different methods are not strictly comparable: a change between them mixes a method change with the forecast change.

      What stands out

      Insights Engine

      Ask a question about the cockpit data in plain English, for example comparing prices, margins, forecasts or SKUs between markets and brands. Answers are written from the cockpit data only. Each answer shows the data it used.

      Each question uses your own Claude usage; the first one asks your permission.

      Data

      1. Download the template. An Excel workbook filled with the data you are looking at now, one sheet per dataset, with a README.
      2. Put in your own numbers. Keep the sheet names and column headers. Amounts in USD, costs as positive numbers.
      3. Load it. The cockpit checks the file and rebuilds every view on your data.

      Your file is read in this browser only and is never uploaded. A loaded pack is remembered in this browser.
